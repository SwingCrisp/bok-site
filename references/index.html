Berliner Philharmoniker · Digital Concert Hall

digitalconcerthall.com

가져올 것
거의 검정 바탕 + 포인트 색 딱 하나(노랑)만 버튼에. 히어로를 화면 끝까지 채우지 않고 여백을 둔 둥근 상자로 넣어 사진 해상도 부담을 줄임. 카드에 ‘상태 라벨 + 일시 + 제목’ 순서.
피할 것
가운데 정렬 안내문이 반복되어 화면이 길어짐.

롯데콘서트홀

lotteconcerthall.com

가져올 것

가져올 것

피할 것

boulezsaal.de

가져올 것
월 탭 + 날짜 숫자 띠: 공연 있는 날만 진하게, 오늘은 빨간 원. 달력 페이지에 들어가지 않아도 한 줄로 한 달이 보임. 메뉴 4개.
피할 것
히어로 영상이 화면 한 장을 통째로 차지.

Philharmonie de Paris

philharmoniedeparis.fr

가져올 것
‘오늘의 공연’ 카드: 큰 시각(8:00 PM) + 장소 + ‘Last tickets’ 상태 + 예매 버튼이 한 카드에. 상단 고정 CALENDAR 버튼. 접근성 안내를 맨 위 띠로 공지.
피할 것
색이 많고 둥근 버튼·상자가 섞여 장식적.
